# Security

## Reporting a vulnerability

Report it privately through GitHub: open the repo's **Security** tab and choose **Report a vulnerability**, or go to https://github.com/smarzban/agent-skills/security/advisories/new.

Do not open a public issue for a security problem.

## Scope

This repo holds agent skills (Markdown instructions and small scripts) and `bin/skills`, which creates links in your home folder and adds a hook to `~/.claude/settings.json`. A report is in scope when a skill or script here can be made to run something its text does not say it runs, or to write outside the places the README names.
